# Security Log Analyzer

A beginner-friendly Python tool for analyzing security logs.

## Features

- Counts INFO, WARNING, and ERROR events
- Detects unknown log entries
- Displays error messages
- Saves a report to `report.txt`

## Requirements

- Python 3.10 or newer

## How to run

1. Download or clone this repository.
2. Make sure `security.log` is in the same folder as `main.py`.
3. Run:

```bash
python main.py
```

## Project structure

- `main.py` — the log analyzer
- `security.log` — sample log data
- `report.txt` — generated report

## Disclaimer

This project is for educational purposes and uses sample log data.
